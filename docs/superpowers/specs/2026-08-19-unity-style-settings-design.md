# Unity 风格设置页设计

## 目标

按 Unity 编辑器设置窗口范式重做设置页：二级导航、行式设置项、固定底栏 Revert/Apply、简洁统一。

## 已确认决策

| 决策项 | 选择 |
|---|---|
| 保存交互 | Revert + Apply；X 仅关闭不回滚（草稿保留） |
| 主题层级 | 二级导航（选择与管理 / UI 外观 / 终端 / ANSI） |
| 行样式 | Unity 行式：label 左、控件右，26px 行高，纯留白，悬停整行淡色高亮 |
| 颜色形态 | 非 ANSI 行式；ANSI 24 色保留三组×8 网格 |
| 窗口骨架 | 880×600（min 720×480），左导航 160px 分组，内容区 16px 边距 |
| 通用页路径信息 | 保留一行弱色提示 |
| Apply 反馈 | 底部绿色"已应用"2s 淡出提示 |

## 导航结构（7 页）

```
设置（分组标题）
  通用
  快捷键
  锁定
主题（分组标题）
  选择与管理
  UI 外观
  终端
  ANSI 调色板
```

选中项：accent 左边线 + 淡背景。`settings_tab: usize` → `SettingsPage` 枚举。

## 页面内容

- **通用**：行为（自动复制）／数据（最大条数、滚动回溯）／维护（清空历史 danger）／一行弱色路径提示
- **快捷键**：动作 label + keycap 按钮（录制），恢复默认按钮
- **锁定**：设置/修改/清除密码按钮（弹窗逻辑不变）
- **主题·选择与管理**：主题行式列表（选中指示、用户主题悬停显示重命名/删除）+ 新建/复制/导入/导出工具行
- **主题·UI 外观**：字体组（字体+字号）＋颜色组（17 行式）＋ ANSI 预览块
- **主题·终端**：字体组（字体+字号+间距+内边距）＋配色模板组＋基础颜色组（6 行式）
- **主题·ANSI**：三组×8 色块网格（悬停显色名）

## 交互

- Apply：提交全部（现有逻辑），显示绿色提示 2s
- Revert：settings_edit/theme_edit 回滚到已保存态
- X / Esc：仅关闭

## 颜色

全部复用 active_theme.app.* 现有字段，零新增 schema。
