# OpenNex 主题系统 V2 设计

## 目标

将分散的视觉配置（UI 黑白主题、UI 字体/字号/颜色、终端配色方案、终端字体/字号/颜色）统一为一个完整的可编辑、可管理、可导入导出的主题系统。

## 核心原则

**一个主题 = 完整视觉快照**。不存在独立的"UI 主题"和"终端主题"，只有完整主题。选择一个主题时，UI、字体和终端样式一起切换。

## 主题结构

```text
ThemeDefinition
├── 元数据
│   ├── format_version (固定为 1)
│   ├── id (稳定标识符，不可修改)
│   ├── name (显示名称，可修改)
│   └── author
├── UI 外观 (AppTheme)
│   ├── app_bg, sidebar, panel, input_bg
│   ├── text, weak_text
│   ├── accent, warning, danger
│   ├── hover, active, border
│   ├── selection_bg, selection_text
│   ├── lock, window_shadow
│   ├── ui_font_families (UI 字体候选列表)       ← V2 新增
│   └── ui_font_size (UI 基础字号)               ← V2 新增
├── 终端外观 (TerminalThemeConfig)
│   ├── foreground, background
│   ├── cursor, selection_bg, selection_text, link
│   ├── normal (ANSI 普通 8 色)
│   ├── bright (ANSI 明亮 8 色)
│   └── dim (ANSI 暗淡 8 色)
└── 字体与尺寸 (TypographyTheme)
    ├── terminal_font_families
    ├── terminal_font_size
    ├── cell_spacing
    └── menu_font_size
```

UI 字号按固定比例派生菜单、按钮、标题等控件字号，不开放分区域独立字号。

## 终端配色模板

One Dark、Solarized、Gruvbox、Dracula、OpenNex Light Terminal 作为**内置只读快速填充模板**：

- 模板不是主题的长期引用。
- 应用模板只覆盖当前主题的终端颜色。
- 不改变 UI 外观、UI 字体、终端字体、字号和间距。
- 应用后用户可继续逐个修改颜色。
- 保存的是实际颜色值，不是模板名称。
- 导出主题自包含，不依赖内置模板是否存在。
- 模板不提供新建、重命名、删除、导入导出。

## 主题管理

### 分类

| 属性 | 内置主题 | 用户主题 |
|------|---------|---------|
| 选择 | ✓ | ✓ |
| 编辑 | 触发自动副本 | ✓ |
| 重命名 | ✗ | ✓ |
| 删除 | ✗ | ✓ |
| 复制 | ✓ | ✓ |
| 导入导出 | ✓ | ✓ |

### 新建主题

- 基于当前主题创建，复制全部 UI 外观、终端外观和字体设置。
- 用户必须输入新主题名称。
- 自动生成唯一主题 ID。
- 确认后立即创建主题文件并切换到新主题。

### 复制主题

- 自动生成副本名称（原名称 + "副本"）。
- 底层逻辑与新建主题相同。

### 编辑内置主题

用户编辑内置只读主题时：

1. 弹出"创建主题副本"对话框。
2. 默认名称为"原主题名称 副本"。
3. 自动生成不冲突的 ID（如 `opennex-dark-copy`、`opennex-dark-copy-2`）。
4. 用户确认后**立即创建主题文件**。
5. 执行用户刚才触发的修改。
6. 用户取消时不创建副本，也不改变当前主题。
7. 原内置主题始终保持只读。

### 保存机制

- **显式保存**：修改颜色、字体、字号和应用模板时实时预览，必须点击"应用"才写入主题文件。
- 点击"关闭"或窗口关闭按钮时回滚未保存修改。
- 已创建的主题副本文件保留，但恢复为刚创建时的原始内容。
- 保存失败时保持编辑状态，显示错误，不丢失当前调整。

### 切换主题遇到未保存修改

显示确认框，提供三个操作：

1. **保存并切换**：校验并保存当前用户主题，然后切换。
2. **放弃并切换**：丢弃草稿，恢复已保存内容，然后切换。
3. **取消**：保持当前主题和编辑内容不变。

菜单栏和设置页的主题切换均遵循相同规则。

### 删除主题

- 只有用户主题可以删除，内置主题不可删除。
- 删除前显示二次确认。
- 当前主题存在未保存修改时，先按"保存并切换 / 放弃并切换 / 取消"处理。
- 删除成功后**始终切换到 `OpenNex Dark`**。
- 同步更新 `settings.json`、设置页下拉框和菜单栏列表。
- 删除失败时保持当前主题不变，显示错误。
- 删除非当前主题时不切换当前主题。

### 重命名

- 只修改显示名称 `name`。
- 内部 `id` 和存储文件名保持不变。
- 重命名后立即更新主题文件。
- 菜单栏和设置页同步刷新。
- 允许不同主题使用相同显示名称，但对重名项补充"用户主题"标识。
- 导出文件默认名称使用稳定 `id`。

### 恢复默认

- 只支持恢复整个主题（完整内容）。
- 不提供分组恢复或单项恢复。
- 用户需要恢复时，整体恢复当前主题的完整内容。
- 内置主题不可修改。
- 终端配色模板仍可重新应用，属于"应用模板"而非"恢复设置"。

## 菜单栏同步

菜单栏"主题"列表和设置页读取同一个主题仓库：

```text
主题
├── OpenNex Dark       ✓ (当前)
├── OpenNex Light
├── Solarized Dark
├── Gruvbox Dark
├── Dracula
├── My Custom Theme
└── 管理主题...         → 打开设置页外观选项卡
```

菜单栏只负责快速切换，不提供新建、删除、导入等复杂操作。

## 设置页布局

```text
外观设置
├── 主题
│   ├── 主题下拉框 [OpenNex Dark ▼]
│   ├── [新建] [复制] [重命名] [删除]
│   └── [导入] [导出]
├── UI 外观
│   ├── UI 字体 [monospace ▼]
│   ├── UI 字号 [14.0]
│   ├── 基础颜色（背景/侧栏/面板/输入框）
│   ├── 文字颜色（普通/弱化）
│   ├── 状态颜色（强调/警告/危险）
│   └── 交互颜色（悬停/激活/选中/边框/锁定/阴影）
└── 终端外观
    ├── 终端字体 [monospace ▼]
    ├── 终端字号 [14.0]
    ├── 单元格间距 [1.0]
    ├── 配色模板 [Gruvbox Dark ▼] [应用模板]
    ├── 基础颜色（前景/背景/光标/选区/链接）
    └── ANSI 调色板（普通/明亮/暗淡 × 8 色）
```

## 跨平台

- 同一 `.opennex-theme.json` 可在 Windows、macOS、Linux 导入。
- 颜色由 egui/egui_term 渲染，三平台一致。
- 字体使用候选列表，当前平台不存在时按序回退到系统字体和内嵌字体。
- 不保存字体文件绝对路径。
- 不修改 shell 配置。

## 不放入主题

以下配置保留在 `settings.json`，不进入主题：

- 语言
- 快捷键
- 历史上限、回滚行数
- 默认 Shell
- 工作区布局
- 锁定密码
- 窗口状态
- 本机路径
